# UI/UX Design Control

For each applicable design stage, prepare three coherent design directions—not three random screens:
A. Clean / Minimal
B. Premium / Brand Focused
C. Modern / Conversion Focused

Client selects one direction. Consolidated feedback is tracked. The selected direction becomes the implementation reference.

FSD approval window: 48 hours from design receipt; client/third-party delays are tracked separately from development defects.
